# oh-my-codes 文档

欢迎查阅 oh-my-codes 文档。

oh-my-codes 是一个 [OpenCode](https://opencode.ai) 插件，为你的 AI 编程助手提供多模型编排、账户与工作区管理以及 Token 用量追踪功能。

---

## 指南

### [快速开始](./get-started.md)

安装 OpenCode 并配置 oh-my-codes，提升你的 AI 编程工作流。
